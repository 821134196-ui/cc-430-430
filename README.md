# 装修材料进场预约与电梯保护确认系统

管理楼栋、装修单元、材料清单、车辆、进场时段、电梯保护点、门岗放行与签收记录。
纯 Python 标准库实现（SQLite 内置，无任何第三方依赖）。

## 一条命令启动

```bash
./run.sh
```

它会：重置演示库 → 写入楼栋/电梯/单元/材料/保护点演示数据 → 自动创建
**预约 → 物业保护确认 → 门岗放行 → 签收差异** 样例（含迟到、超重、保护板缺失、
电梯故障、错楼栋五类异常登记、占位过期释放、临时加材料复核）→ 启动 Web：

- 首页楼栋日历：http://localhost:8000/
- 门岗核验（大字号车牌/时段/放行结果）：http://localhost:8000/gate

其他命令：`./run.sh serve`（保留数据启动）、`./run.sh reset`、`./run.sh test`。

## 页面

| 页面 | 路径 | 说明 |
|---|---|---|
| 楼栋日历 | `/` | 按楼栋 → **电梯分栏**展示 30 分钟时段占用 |
| 车辆预约 | `/booking` | 选单元/电梯/时段/车牌建预约，进入 held 占位 |
| 材料清单 | `/materials` | 醒目重量数字 + 超限/超长工程橙标记 |
| 保护点位 | `/protection` | 待物业确认列表、各楼栋保护点台账 |
| 预约详情 | `/appt?id=N` | 巡检拍照、物业确认、临时加材料、门岗记录、签收 |
| 门岗核验 | `/gate` | 大字号车牌、时段、放行结果；只读取必要字段 |
| 签收差异 | `/signoffs` | 短少/多出/损坏差异台账 |

配色为白色底、深森林绿导航与状态、工程橙操作/警示。

## 业务规则

- **容量分配**：同一电梯同一 30 分钟时段只允许一辆车（部分唯一索引兜底）；
  装卸区按楼栋车位容量限制（`bay_ticket` 唯一行）。并发双击只放行一辆车。
- **占位过期**：预约先占 `held`，默认 15 分钟（`APP_HOLD_TTL`）内未完成物业
  保护确认、或时段已结束仍未确认，自动 `released` 并回收梯位/车位。
- **保护确认才放行**：必设保护点全部到位且物业批准后才 `confirmed`；
  门岗还会现场复查保护板在位。**临时增加材料**会标记待复核，必须物业重新
  确认保护方案，门岗才放行（`material_addition.rechecked`）。
- **重量边界**：申报总重恰好等于电梯额定载重可约、可放行；超出（哪怕 0.1kg）
  预约阶段或门岗阶段拒绝并登记 `overweight`。车辆/称重由模拟适配器提供。
- **状态机**：`held → confirmed → gate_passed → arrived → signed`，
  `released` 为过期终态；**已签收（signed）材料不能回退为未到场**。
- **签收幂等**：一个预约只有一条签收（唯一约束），重复提交返回首条并标记
  `idempotent`，按材料登记短少/多出等差异。
- **字段脱敏**：门岗视图为字段白名单（车牌、承运商、楼栋房号、电梯、时段、
  总重/额定载重、状态、实测重），住户姓名电话、司机电话、详细地址均不下发。
- **异常登记**：迟到 `late`、超重 `overweight`、保护板缺失 `no_protection`、
  电梯故障 `elevator_fault`、错楼栋 `wrong_building`、签收差异逐次写入
  `gate_record` / `signoff_item`，可审计可回溯。

## 模拟适配器（`app/adapters.py`）

- `VehicleAdapter`：车辆/承运商/司机档案与可进入楼栋备案（错楼栋判定）。
- `WeighbridgeAdapter`：`exact` 精确、`jitter` ±3% 正常波动、
  `overweight` 强制超重演练、`fault` 地磅故障。门岗页可切换。

## 存储

- SQLite：`data/booking.db`（预约、材料、保护、门岗、签收）。
- 保护照片：`data/photos/`（真实环境替换为巡检 App 上传；演示环境用标准库
  zlib/struct 生成带工程橙斜纹的占位 PNG，同样落盘本地目录）。

环境变量：`APP_DB_PATH`、`APP_PHOTO_DIR`、`APP_PORT`、`APP_HOLD_TTL`。

## 测试

```bash
./run.sh test
```

覆盖：容量竞争（多线程抢占梯位/并发门岗双击）、占位过期（TTL/时段结束/回收
再约）、重量边界（等于载重放行 / 超 0.1kg 拒绝）、字段脱敏（门岗白名单与
页面无电话）、签收幂等（重复提交唯一、已签收不可回退、差异登记）。

## 结构

```

  db.py         SQLite schema、连接、BEGIN IMMEDIATE 事务
  adapters.py   车辆 / 地磅模拟适配器
  services.py   预约容量、过期释放、保护确认、门岗、签收
  photos.py     保护照片落盘与演示占位 PNG
  seed.py       楼栋/电梯/单元/住户/材料/保护点演示数据
  demo.py       一键样例（正常全流程 + 五类异常 + 过期/复核）
  ui.py         stdlib http.server 六个页面
tests/test_services.py
run.sh          单条本地启动命令
```
