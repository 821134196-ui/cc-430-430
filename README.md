# 装修材料进场预约与电梯保护确认系统

管理楼栋、装修单元、材料清单、车辆、进场时段、电梯保护点、门岗放行与签收记录。
纯 Python 标准库 + SQLite，零第三方依赖；地址、住户、车牌均为演示数据。

## 单条命令启动（含样例）

```bash
./run.sh
```

等价于 `python3 -m app.cli up`，会依次完成：

1. 建库 + 写入演示数据（2 栋楼、电梯、装卸区、3 个装修单元、材料清单、保护点位）
2. 样例 A：预约 → 物业确认保护方案（照片存本地目录）→ 门岗放行 → 签收（一致）
3. 样例 B：预约 → 保护确认 → 放行 → 签收（数量差异，自动登记签收差异异常）
4. 启动 Web 服务 http://127.0.0.1:8000

其他命令：

```bash
python3 -m app.cli demo    # 只跑样例工作流，不启动服务
python3 -m app.cli serve   # 只启动 Web 服务
python3 -m app.cli reset   # 清空本地数据库与保护照片
python3 -m unittest discover -s tests -v   # 运行测试（26 个用例）
```

## 页面

| 路径 | 功能 |
|---|---|
| `/` | 楼栋日历：按电梯分栏 × 时段，显示车牌/房号/状态/重量/超长 |
| `/materials` | 材料清单：醒目大字号重量、超限标记、临时增改材料、重新核验 |
| `/protection` | 保护点位：必检点勾选、保护照片（本地目录存储）、确认放行 |
| `/booking` | 车辆预约：楼栋/电梯/装卸区/时段/车牌，容量自动分配 |
| `/gate` | 门岗核验：大字号车牌、时段、放行结果，只读必要字段（脱敏） |
| `/signoff` | 签收与差异：应收/实收对照，差异自动登记 |
| `/exceptions` | 异常登记：迟到/超重/保护板缺失/电梯故障/错楼栋/签收差异 |

## 业务规则

- **容量分配**：按楼栋装卸区总数、每台电梯、每个装卸车位三级容量占用时段名额；
  占用在 `BEGIN IMMEDIATE` 写事务内完成，并发下同名额只有一辆车成功。
- **占位过期**：预约创建后占位 20 分钟（`APP_HOLD_MINUTES`），物业未确认保护方案
  自动释放名额；已确认但时段结束仍未到场同样释放。
- **保护确认**：全部必检保护点完成且有照片才可确认；确认后门岗才能放行。
- **临时增改材料**：清单版本 +1 并置为「待重新核验」，必须物业重新核验后才能
  确认保护方案/再预约；重新核验时复查电梯载重并同步预约快照。
- **门岗放行**：校验错楼栋、电梯故障、迟到（时段开始 +15 分钟宽限）、
  保护板缺失、地磅实称超重（模拟适配器），任一不满足即拒绝并登记异常；
  `gate_pass.appointment_id` 唯一约束保证并发只放行一次。
- **门岗脱敏**：门岗视图只含单号/车牌/司机/楼栋/电梯/时段/状态/重量/超长，
  不含住户姓名、电话、房号。
- **签收**：按预约唯一（幂等，重复提交返回首次记录）；实收与清单不一致自动
  登记签收差异；签收为终态，状态机不允许回退为未到场。

## 存储与适配器

- SQLite：`data/renovation.db`（预约、材料、保护、放行、签收、异常）
- 保护照片：本地目录 `data/photos/`（未上传时生成占位 PNG）
- 模拟适配器 `app/adapters.py`：车辆登记白名单、地磅称重（可注入超重偏差）

## 界面

白色底、深森林绿（#1b4332）主色、工程橙（#f77f00）强调色；
材料重量大字号 + 超限红色标记；门岗端 64px 车牌、34px 时段、大色块放行结果。

## 测试覆盖（tests/test_system.py，26 例）

容量竞争（8 线程抢 1 名额、楼栋装卸区容量、6 线程并发只放行一次）、
占位过期（释放名额可再约、时段结束释放）、重量边界（申报=上限通过、
申报>上限拒绝、实称=上限放行、实称>上限登记超重、超长阈值边界）、
字段脱敏（门岗视图无住户隐私）、签收幂等（重复签收返回首次记录、
篡改数量不生效）、签收差异登记、签收终态不可回退、临时增改材料必须
重新核验、错楼栋/电梯故障/保护板缺失/迟到/未确认保护均拒绝放行。
